# Impeccable repack

This fork distributes upstream Impeccable skill releases through portable plugin archives and a remote marketplace.

## Language

**Upstream release**:
A published stable release of the original Impeccable skill. CLI and browser-extension releases are separate products.

**Upstream baseline**:
The exact upstream release incorporated into a repack, identified by its release tag, source commit, and consumed assets.

**Repack**:
The upstream plugin payload with the distribution wrapper, attribution, and provenance needed by the selected consumers. Its upstream skill content and embedded version remain unchanged.

**Repack release**:
A published version of the repack, distinct from its upstream baseline. A packaging correction is a new repack release even when the upstream baseline stays the same.

**Qualified marketplace snapshot**:
The catalog and plugin payload that have passed the selected publication checks. Availability of this snapshot does not establish that a consumer has synchronized or loaded it.
